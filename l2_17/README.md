`telnet` — это telnet-клиент, позволяющий подключаться к любому TCP-серверу и вручную взаимодействовать с ним через терминал.

всё, что вы вводите — отправляется серверу,
всё, что присылает сервер — выводится на экран.

---

## Сборка

В корне проекта:

```bash
go build -o telnetx cmd/main.go
```

После этого появится исполняемый файл `telmetx`.

---

## Использование

```bash
./telnetx host port [--timeout N]
```

* `host` — имя хоста или IP
* `port` — номер TCP-порта
* `--timeout` — таймаут подключения в секундах (по умолчанию 10)

### Примеры

Подключение к локальному серверу:

```bash
./telnetx localhost 12345
```

С таймаутом 5 секунд:

```bash
./telnetx localhost 12345 --timeout 5
```

Подключение к SMTP-серверу:

```bash
./telnetx smtp.gmail.com 25
```

---

## Как завершить работу

* **Ctrl+D** — закрыть соединение и выйти
* Если сервер закрыл соединение — клиент автоматически завершится

## Как тестировать

### Echo-сервер

В одном терминале:

```bash
nc -l 12345
```

В другом:

```bash
./telnetx localhost 12345
```
