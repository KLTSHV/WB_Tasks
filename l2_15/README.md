Minishell

Возможности

Встроенные команды (builtins)
	•	cd <path> — смена текущей директории
	•	pwd — вывод текущей директории
	•	echo <args> — вывод аргументов
	•	kill <pid> — отправка SIGTERM процессу
	•	ps — список процессов (через внешнюю ps)

Внешние команды
	•	Запуск любых программ через fork/exec (os/exec)
	•	Корректное ожидание завершения и возврат exit-кода

Конвейеры (pipelines)
	•	Объединение команд через |
	•	Пример:

ps | grep zsh | wc -l



Условное выполнение
	•	cmd1 && cmd2 — cmd2 выполняется только при успешном cmd1
	•	cmd1 || cmd2 — cmd2 выполняется при ошибке cmd1

Редиректы
	•	< file — ввод из файла
	•	> file — вывод в файл (truncate)
	•	Пример:

cat < in.txt | wc -l > out.txt



Переменные окружения
	•	Подстановка $VAR внутри аргументов

echo $HOME

Сигналы
	•	Ctrl+D — завершение shell (EOF)
	•	Ctrl+C — прерывание текущей команды или pipeline без завершения shell

⸻

Ограничения (MVP)

Ограничения:
	•	нет кавычек ("...", '...') и экранирования
	•	нет job-control (&, bg, fg)
	•	нет расширенных редиректов (>>, 2>, heredoc)
	•	cd запрещён в pipeline

Эти ограничения упрощают реализацию и соответствуют учебной задаче.

Сборка и запуск

Запуск интерактивно

Из корня проекта:

go run ./cmd/minishell

Запуск со скриптом

go run ./cmd/minishell < script.sh

Примеры использования

pwd
cd /tmp
echo hello world

ls | wc -l
echo a a a | wc -w

false && echo fail
true  || echo fail

echo hello > out.txt
cat < out.txt

Реализация 
	•	Внешние команды запускаются через os/exec
	•	Конвейеры реализованы с помощью os.Pipe
	•	Для pipeline создаётся отдельная process group (Setpgid)
	•	Ctrl+C отправляет SIGINT всей группе процессов
	•	Ресурсы (pipe, файлы) закрываются корректно, зомби-процессов нет
